# SIH Evaluator Presentation Mode

## Overview
Presentation Mode optimizes the PROCUREX UI for live evaluation demonstrations on projectors and laptops.

## Featured Demonstrations
1. **Scenario S (Officer Override)**: Shows system recommendation `MANUAL_REVIEW_REQUIRED`, officer investigation, officer approval, mandatory written justification, override flag (`is_override = True`), and tamper-evident audit logging.
2. **Scenario W (Audit Tamper Detection)**: Verifies valid SHA-256 audit chain, simulates payload alteration, and proves automated tamper detection (`status: INVALID`).
