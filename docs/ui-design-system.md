# Design System & Mission Control Theme

## Color Palette
- **Background Foundation**: Deep Dark Slate (`slate-950` / `#020617`, `navy-950`)
- **Card Surfaces**: Dark Navy Slate (`slate-900/60` / `#0f172a`, `slate-950`)
- **Text & Hierarchy**: White (`#ffffff`), Slate 200 (`#e2e8f0`), Slate 400 (`#94a3b8`)
- **Status Semantics**:
  - `PASS` / `VERIFIED` / `APPROVED` / `VALID` -> Emerald (`#10b981`)
  - `MANUAL_REVIEW_REQUIRED` / `REVIEW` / `STALE` -> Amber (`#f59e0b`)
  - `FAIL` / `REJECTED` / `BLOCKED` / `INVALID` -> Rose (`#f43f5e`)
  - `UNAVAILABLE` / `INCOMPLETE` -> Slate (`#64748b`)
